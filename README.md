# Noelithub77.github.io

The Pokémon Showdown Mobile invite lives at `/pokemon-showdown-mobile/invite`. Valid Android links open the installed app through Android App Links or an `intent://` fallback. If the app is not installed, the page offers the latest signed APK. `.well-known/assetlinks.json` contains the SHA-256 fingerprint for the reused Bunkialo EAS Android signing certificate.
